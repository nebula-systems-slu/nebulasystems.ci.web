# Nebula Systems

Software Development & Cloud Computing Solutions.

## Tecnologias

- React + TypeScript + Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion (animações)

## Desenvolvimento

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Build para produção
npm run build
```

## Estrutura

```
src/
├── components/     # Componentes React
├── pages/          # Páginas da aplicação
├── router/         # Configuração de rotas
├── hooks/          # Custom hooks
├── lib/            # Utilitários
└── assets/         # Imagens e assets
```
